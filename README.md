# agentesPRO Client Bootstrap

Single-source bootstrap package for installing and verifying a new agentesPRO client Hermes VPS.

## One URL for client Hermes agents

Give the target Hermes agent this URL and say: **install the agentesPRO client baseline from this**.

```text
https://raw.githubusercontent.com/larvuz2/agentespro-client-bootstrap/main/BOOTSTRAP.md
```

## What it covers

- baseline agentesPRO skills
- client Memory OS context pack
- Obsidian-compatible client vault
- dashboard connector registration
- heartbeat/sync/activity checks
- recurring cron-job sync checks
- Agent vs Project modeling rules
- safe dashboard data rules
- final onboarding acceptance checklist
